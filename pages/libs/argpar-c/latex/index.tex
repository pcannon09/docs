Typical usage:\+


\begin{DoxyEnumerate}
\item Initialize parser ({\ttfamily \doxylink{APC__ArgParser_8h_a61d4424e1c28b49745d42226a00c60f4}{apc\+\_\+init}})
\item Create argument definitions that can be modified ({\ttfamily \doxylink{APC__ArgParser_8h_a89cd1dbd57bfa347f76c06add302ed98}{apc\+\_\+init\+Info}})
\item Register arguments ({\ttfamily \doxylink{APC__ArgParser_8h_a249d5856e4d70717a20b468fd5600bbd}{apc\+\_\+add}})
\item Query arguments ({\ttfamily \doxylink{APC__ArgParser_8h_a00b47bfc8947418ae1f908f4de1f5f1e}{apc\+\_\+get}})
\item Optionally generate help ({\ttfamily \doxylink{APC__ArgParser_8h_a235f33a098769075131ad521168d2e0a}{apc\+\_\+generate\+Help}})
\item Destroy parser ({\ttfamily \doxylink{APC__ArgParser_8h_acce093adeb486562d49b2e483102abbf}{apc\+\_\+destroy}})
\end{DoxyEnumerate}

The API is intentionally minimal and explicit, designed to remain simple, predictable, and suitable for low-\/level C projects
