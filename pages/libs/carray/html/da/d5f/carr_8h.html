Deletes an element at a specified index.

Removes the element at index from the vector.

Parameters

[in]indexIndex of the element to delete.
[in]fallControls the deletion behavior, as defined by the implementation.
Returns
CARR_VEC_OK if successful.

CARR_VEC_NULL if a required pointer is NULL.

Parameters

Reverses the order of elements in the vector.

Parameters

Returns
CARR_VEC_OK if successful.
