\doxysubsection{Detailed Description}
Represents a pointer-\/based vector container. 

Stores pointers to elements in a contiguous array. Tracks the number of elements currently stored and the allocated capacity.

\begin{DoxyWarning}{Warning}
Avoid modifying the internal fields directly
