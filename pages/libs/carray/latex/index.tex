\doxylink{structCARR}{CARR} is a lightweight C vector library that stores pointers to elements ({\ttfamily void \texorpdfstring{$\ast$}{*}}). It supports insertion, replacement, deletion, reversal, and dynamic resizing.\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{index_autotoc_md3}

\begin{DoxyItemize}
\item {\bfseries{C standard:}} C99 or later.
\item {\bfseries{Compilers:}} GCC, Clang, or MSVC. Other compilers {\itshape might} also support CArray
\item {\bfseries{Minimum compiler versions:}} GCC 3.\+0+, Clang 3.\+0+, or MSVC 2013+
\item {\bfseries{Dependencies:}} Standard C headers and the \doxylink{structCARR}{CARR} implementation, no other dependencies needed
\end{DoxyItemize}\hypertarget{index_autotoc_md4}{}\doxysection{\texorpdfstring{Setup}{Setup}}\label{index_autotoc_md4}

Check returned {\ttfamily \doxylink{carr_8h_ab4bdc8444943761b4337de9fe5b718ec}{CARRError}} values to handle operation failures.\hypertarget{index_autotoc_md7}{}\doxysection{\texorpdfstring{Notes}{Notes}}\label{index_autotoc_md7}

\begin{DoxyItemize}
\item \doxylink{structCARR}{CARR} stores pointers rather than copies of elements. Ensure the pointed-\/to objects remain valid while they are used.
\item {\ttfamily carr\+\_\+init(4, true)} initializes the vector with a capacity of four and enables dynamic resizing.
\item {\ttfamily \doxylink{carr_8h_a8f8ef750f811b48ace4c344919cb309b}{carr\+\_\+destroy()}} releases the vector\textquotesingle{}s internal resources; it does not necessarily free the pointed-\/to elements.
\item The meaning of the {\ttfamily fall} parameter in {\ttfamily \doxylink{carr_8h_a6eafd445d5ca5592e6b060f0ac8057a0}{carr\+\_\+delete\+Index()}} depends on the implementation. 
\end{DoxyItemize}
